## Actividad 6 - Turismo Chillán Digital

Se desarrolló una aplicación SPA utilizando Vue 3 y Vue Router.

### Funcionalidades

- Página de Inicio.
- Sección de atractivos turísticos.
- Sección de gastronomía.
- Formulario de contacto.
- Navegación mediante Vue Router.
- Navbar reutilizable.
- Componente TarjetaLugar utilizando props.
- Diseño responsive básico.
